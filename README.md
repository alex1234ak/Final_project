# Итоговый проект: Веб-сервер для задач

## Описание
Этот проект реализует веб-сервер для управления задачами с поддержкой повторяющихся событий, API и фронтенда.

## Структура проекта
- `main.go` — точка входа, запуск сервера
- `pkg/` — основная бизнес-логика и работа с БД
  - `db/` — работа с SQLite, модели и методы для задач
  - `api/` — обработчики HTTP API
  - `server/` — запуск и конфигурация сервера
- `web/` — фронтенд (HTML, CSS, JS)
- `tests/` — автотесты для проверки API и функционала

## Зависимости
- Go 1.18+
- SQLite (через modernc.org/sqlite)
- testify (для тестов)

## Как запустить
1. Установите зависимости:
   ```bash
   go mod tidy
   ```
2. Запустите сервер:
   ```bash
   go run main.go
   ```
   По умолчанию сервер стартует на http://localhost:7540
3. Откройте в браузере `web/index.html` или обращайтесь к API напрямую.

## API
- `POST /api/task` — добавить задачу
- `GET /api/task?id=...` — получить задачу
- `PUT /api/task` — изменить задачу
- `DELETE /api/task?id=...` — удалить задачу
- `GET /api/tasks` — получить список задач
- `POST /api/task/done?id=...` — отметить задачу выполненной
- `GET /api/nextdate?...` — рассчитать следующую дату по правилу

## Тестирование
1. Убедитесь, что сервер запущен на порту 7540 (или укажите переменную окружения TODO_PORT).
2. Запустите тесты:
   ```bash
   go test ./tests/...
   ```
